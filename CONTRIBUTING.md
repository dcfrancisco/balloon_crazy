Thanks for your interest in contributing to Balloon CRAZY!

Short guidelines to help contributors get started:

- File issues for bugs or feature requests. Use clear titles and steps to reproduce.
- Before opening a PR, please:
  - Check existing issues and PRs to avoid duplicates.
  - Open an issue first for non-trivial changes to discuss design.
- Coding style:
  - Follow the existing Dart/Flutter project style. Prefer small, focused PRs.
  - Run the analyzer and formatter: `flutter analyze` and `dart format .` before submitting.
- Tests:
  - Add unit/widget tests for new logic when practical.
  - Run tests: `flutter test`.
- Pull requests:
  - Target the `main` branch by default, or open a PR against a relevant feature branch.
  - Include a brief description and link to related issues.
  - Keep commits squashed/clean (we can squash on merge if preferred).

Maintainers and approvals
- Currently, contributions require approval by the repository owner(s). If you see a `review required` status on a PR, that means it needs a maintainer's approval before merging.
- If you'd like to become a co-maintainer, please open an issue or contact the current maintainer (see the `README.md` for contact links).

Thanks — contributions are appreciated!
